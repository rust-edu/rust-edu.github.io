## LaTeX Refereed Paper Format

Here lies a super-simplified LaTeX conference paper format
intended for the Rust Workshop 2022.

* [`rust-edu-workshop.cls`](/workshop/paper-format-latex/rust-edu-workshop.cls): LaTeX
  paper macros.

* [`sample.tex`](/workshop/paper-format-latex/sample.tex): LaTeX sample / template paper.

* [`sample.bib`](/workshop/paper-format-latex/sample.bib): BibTeX bibliography for sample
  / template paper.

* [`sample.pdf`](/workshop/paper-format-latex/sample.pdf): Formatted sample paper.
